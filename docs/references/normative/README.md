# Referencias normativas públicas

Estos archivos son copias locales de documentos públicos enlazados desde SMIE para investigación y trazabilidad del prototipo. No son una base normativa completa ni autorizan el uso del software para emitir diseño.

| Archivo local | Fuente | Uso en el prototipo |
| --- | --- | --- |
| `ntc-concreto-cdmx-2017.pdf` | [SMIE](https://www.smie.org.mx/uploads/1/2022-11/normas_tecnicas_complementarias_diseno_construccion_estructuras_concreto_2017.pdf) | Concreto simple, reforzado y presforzado; unidades, estados límite y detallado |
| `ntc-acero-cdmx-2020.pdf` | [SMIE](https://www.smie.org.mx/uploads/1/2022-11/ntc_acero_2020.pdf) | Referencia de diseño y construcción de acero |
| `ntc-sismo-cdmx-2020.pdf` | [SMIE](https://www.smie.org.mx/uploads/1/2022-11/normas_tecnicas_complementarias_diseno_sismo_2020.pdf) | Referencia sísmica pública con comentarios |
| `ntc-viento-cdmx-2017.pdf` | [SMIE](https://www.smie.org.mx/uploads/1/2022-11/normas_tecnicas_complementarias_diseno_viento_2017.pdf) | Referencia de viento |

Los códigos ACI/AISC/ASCE y manuales PCI/PTI se mantienen como enlaces y metadatos hasta contar con una fuente/licencia que permita redistribución. El código debe guardar la edición y la cláusula, no copiar capítulos completos.
