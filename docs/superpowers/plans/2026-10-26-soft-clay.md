# Soft Clay Implementation Plan

> Ejecución directa con Superpowers; no hay agente auxiliar autenticado.

**Goal:** Limpiar las familias compartidas sin perder clay ni funciones.
**Architecture:** Perfil de materia en `src/design-system/softClay.css`, importado en `main.tsx`. Selectores por rol con especificidad explícita para resistir chunks lazy. Sin overrides universales de botones ni `!important`.
**Spec:** `../specs/2026-10-26-soft-clay-design.md`
**Tech Stack:** React, CSS, Vite, Vitest, Playwright.

## Restricciones
Conservar marca, semántica, objetivos táctiles y foco. Ningún cambio de motor, datos, dependencias o rutas. No tests para congelar estilo/copy, según AGENTS.md.
